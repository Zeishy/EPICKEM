# ADR-NNN : Titre court, sous forme de décision

- **Statut** : Proposé | Accepté | Remplacé par ADR-NNN | Abandonné
- **Date** : AAAA-MM-JJ
- **Issue** : #NN

## Contexte

Le problème à résoudre et les contraintes qui pèsent sur la décision : exigences du sujet, délais, compétences de l'équipe, limites techniques. Les faits, pas encore la solution.

## Options envisagées

### Option A : nom

- **Pour** : …
- **Contre** : …

### Option B : nom

- **Pour** : …
- **Contre** : …

## Décision

L'option retenue, en une phrase, puis pourquoi elle l'emporte sur les autres.

## Conséquences

- **Positives** : ce que la décision rend plus simple.
- **Négatives** : ce qu'elle coûte ou rend plus difficile, et comment on le limite.
- **Suivi** : les issues ou les points à revoir plus tard.
